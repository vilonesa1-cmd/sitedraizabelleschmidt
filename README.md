# Izabelle Damázio Schmidt | Odontologia Estética

Site institucional estático em HTML5, CSS3 e JavaScript puro. Não precisa de compilação.

## Para abrir o site completo

**Baixe o ZIP e extraia a pasta inteira antes de abrir o `index.html`.** O site depende de `style.css`, dos scripts e das pastas `assets/` e `images/`. Baixar somente o arquivo `index.html` faz com que o estilo, as fotos ou as interações não carreguem.

Depois de extrair, abra `index.html` dentro da pasta `site-gris-completo`. Mantenha todos os arquivos e subpastas juntos.

## Arquivos

- `index.html`: página principal.
- `style.css`: identidade visual, tipografia, animações e responsividade.
- `script.js`, `cases.js` e `reviews.js`: interações, casos e avaliações.
- `simulador-avaliacao.html` e `simulator.js`: simulador de avaliação.
- `assets/` e `images/`: logotipo, retratos e fotos dos casos.
- `privacidade.html`: informações de privacidade.
- `INFORMACOES-DO-PROJETO.md`: resumo do conteúdo e das decisões do projeto.
- `INFORMACAO-PENDENTE.md`: dado profissional a confirmar antes da publicação.

## Testar localmente

Você pode abrir o `index.html` após extrair a pasta. Para uma visualização local mais fiel, abra a pasta no Visual Studio Code e use uma extensão como Live Server. Não há dependências nem comando de compilação.

## Publicar no GitHub Pages

1. Envie o conteúdo desta pasta à raiz de um repositório GitHub.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione a branch e a pasta **/(root)** e salve.

Mantenha todos os arquivos e pastas juntos na raiz do repositório. Os caminhos de recursos são relativos, compatíveis com GitHub Pages.

## Dados a confirmar antes de publicar

Preencha o número e a UF do CRO no marcador indicado em `INFORMACAO-PENDENTE.md`. Confirme também os dados legais do controlador, a política de privacidade e as autorizações de uso das imagens de casos clínicos.
